# CRC32 Checker 1.0.0

Первый публичный релиз: portable-приложение для Windows x64 с русским
графическим интерфейсом для вычисления CRC32 файлов `.bin` и `.hex`.

## Возможности

- CRC-32/ISO-HDLC по байтам BIN или исходным байтам любого файла.
- Intel HEX: проверка строк, типы записей 00–05, расширенные адреса.
- Расчёт по адресному диапазону данных, внутренние промежутки заполняются FF.
- Просмотр CRC32, размеров, адресов и количества байтов заполнения.
- Фоновый расчёт, отмена, копирование и обработка ошибок.
- Версия, авторство и лицензии доступны в меню «Справка → О программе».

## Загрузка

- **CRC32Checker.exe** — один portable-файл, без установки Python.
- **CRC32Checker-1.0.0-windows-x64-portable.zip** — EXE, инструкция и лицензии.
- **SHA256SUMS.txt** — SHA-256 для EXE и ZIP.
- Исходники доступны в репозитории и автоматически создаваемых GitHub архивах.

Распакуйте ZIP или скачайте EXE и запустите двойным щелчком.
Поддерживаются Windows 10/11 x64. Сборка проверена на Windows 10 x64:
20 тестов и отдельная проверка EXE в папке без исходников и Python в PATH.

Для сравнения CRC32 прошивки используйте одинаковый алгоритм, диапазон
адресов и заполнение промежутков. Обычный текстовый hex-дамп не является
Intel HEX; его можно проверить как исходные байты файла.
