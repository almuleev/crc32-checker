# Описание проекта для GitHub

**Название:** CRC32 Checker

**Репозиторий:** `almuleev/crc32-checker`

**GitHub About:** Portable Windows GUI for CRC32 checksums of BIN files and Intel HEX firmware images.

**Описание на русском:** Portable-утилита для Windows с простым русским
графическим интерфейсом для просмотра CRC32 файлов BIN и прошивок Intel HEX.
Поддерживает проверку HEX-записей, расширенные адреса, заполнение промежутков
FF, фоновый расчёт, отмену и копирование результата. Не требует установки Python.

**Topics:** `crc32`, `checksum`, `intel-hex`, `firmware`, `binary-files`,
`windows`, `portable`, `python`, `tkinter`, `gui`, `mit-license`.

**Автор:** Aleksandr Muleev — [@almuleev](https://github.com/almuleev).

**Лицензия исходного кода:** MIT.

**Первый релиз:** `v1.0.0` — CRC32 Checker 1.0.0.
