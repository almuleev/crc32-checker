# CRC32 Checker 1.1.0

Добавлено перетаскивание файлов из Проводника Windows в окно программы.
Перетащите один `.bin` или `.hex` на любую часть главного окна — расчёт
CRC32 начнётся автоматически с сохранением выбранного режима обработки.

## Изменения

- Приём файла над фоном окна и его элементами управления.
- Поддержка кириллицы, пробелов и скобок в путях.
- Понятное сообщение при выборе папки или нескольких файлов.
- Приём новых файлов отключается на время расчёта.
- Нативная реализация Windows без дополнительных библиотек.
- 27 тестов, включая Windows-сообщения перетаскивания; проверка drag-and-drop
  также включена в диагностику собранного portable EXE.
- Среда упаковки зафиксирована: Python 3.14.4 x64, Tcl/Tk 8.6 и PyInstaller 6.20.0.

## Загрузка

- **CRC32Checker.exe** — один portable-файл для Windows 10/11 x64.
- **CRC32Checker-1.1.0-windows-x64-portable.zip** — EXE, инструкция и лицензии.
- **SHA256SUMS.txt** — SHA-256 для EXE и ZIP.

Установка и Python не требуются. Скачайте EXE или распакуйте ZIP и запустите
`CRC32Checker.exe`. Обычный выбор файла через кнопку сохранён.
