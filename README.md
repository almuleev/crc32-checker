# CRC32 Checker

[![Tests and portable build](https://github.com/almuleev/crc32-checker/actions/workflows/ci.yml/badge.svg)](https://github.com/almuleev/crc32-checker/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/almuleev/crc32-checker)](https://github.com/almuleev/crc32-checker/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

**Portable Windows GUI for CRC32 checksums of BIN files and Intel HEX firmware images.**

Простая утилита для просмотра контрольной суммы CRC32 двоичных файлов и
прошивок Intel HEX. Русский интерфейс, один portable EXE, без установки Python
и сторонних библиотек на компьютере пользователя.

## Скачать и запустить

**[Скачать последнюю версию](https://github.com/almuleev/crc32-checker/releases/latest)**

| Файл релиза | Содержимое |
| --- | --- |
| `CRC32Checker.exe` | Один готовый portable EXE |
| `CRC32Checker-1.0.0-windows-x64-portable.zip` | EXE, инструкция, сведения о релизе и лицензии |
| `SHA256SUMS.txt` | SHA-256 для проверки загруженных EXE и ZIP |

Скачайте EXE или распакуйте ZIP и дважды щёлкните `CRC32Checker.exe`.
Системные требования: **Windows 10/11 x64**. Программу можно запускать с флешки;
установка и права администратора не нужны. Python и Tcl/Tk включены в EXE.
При запуске зависимости распаковываются во временную папку пользователя;
после штатного закрытия она удаляется. Настройки и файлы в реестре не создаются.

Проверка SHA-256 в PowerShell:

```powershell
Get-FileHash .\CRC32Checker.exe -Algorithm SHA256
```

Сравните результат со строкой `CRC32Checker.exe` в `SHA256SUMS.txt`.

## Возможности

- Выбор `.bin` и `.hex` через стандартный диалог Windows.
- CRC-32/ISO-HDLC с отображением восьми шестнадцатеричных цифр.
- Два режима: данные Intel HEX либо исходные байты файла.
- Проверка контрольных сумм и структуры записей Intel HEX.
- Показ адресного диапазона, размера данных и заполнения промежутков.
- Расчёт в фоне, индикатор выполнения и отмена.
- Копирование CRC32 в буфер обмена.
- Авторство, версия и лицензии в меню «Справка → О программе».

## Использование

1. Нажмите **«Выбрать файл…»**. Расчёт начнётся автоматически.
2. При необходимости измените режим и нажмите **«Вычислить CRC32»**.
3. Посмотрите результат и описание рассчитанных данных.
4. Нажмите **«Копировать»**, чтобы скопировать сумму без префикса `0x`.

`Ctrl+O` открывает выбор файла. `Esc` отменяет текущий расчёт.
Проверяемый файл не изменяется.

## Что входит в CRC32

| Режим | Данные для расчёта |
| --- | --- |
| Авто, `.bin` | Все байты от начала до конца файла |
| Авто, `.hex` | Данные Intel HEX в порядке возрастания адресов |
| Исходные байты файла | Все байты, включая текст, BOM и переводы строк `.hex` |

### Intel HEX

Расчёт охватывает **минимальный–максимальный адрес данных включительно**.
Внутренние промежутки заполняются байтами **`FF`**. Байты до первого и после
последнего адреса не добавляются. Синтаксис строк, их контрольные суммы,
адреса запуска и служебные записи в CRC32 не входят.

Поддерживаются типы записей `00`–`05`, расширенные сегментные и линейные
адреса, UTF-8 BOM и переводы строк LF/CRLF. Записи сортируются по адресу.
Повреждённые строки, некорректные длины, перекрытие данных, отсутствующий EOF
и записи после EOF считаются ошибкой. Регистр расширения файла не важен.

Для совпадения с другой утилитой должны совпадать **алгоритм, адресный диапазон
и байт заполнения промежутков**. Эти параметры особенно важны для прошивок.

Intel HEX — текстовый формат с записями, начинающимися с `:`. Для других
форматов `.hex` доступен режим исходных байтов. Дамп вроде `AA BB CC` в этом
режиме проверяется как текст и не преобразуется в байты `AA`, `BB`, `CC`.

### Алгоритм

Используется `zlib.crc32`, **CRC-32/ISO-HDLC**, также известный как CRC-32/IEEE.

| Параметр | Значение |
| --- | --- |
| Ширина | 32 бита |
| Полином | `0x04C11DB7` |
| Отражённый полином | `0xEDB88320` |
| Начальное значение | `0xFFFFFFFF` |
| RefIn / RefOut | `true` / `true` |
| Финальный XOR | `0xFFFFFFFF` |
| ASCII `123456789` | `CBF43926` |
| Пустой бинарный файл | `00000000` |

CRC32 проверяет целостность и не является криптографическим хешем.

## Запуск из исходников

Нужен **Python 3.8+ с Tkinter**. В установщике Python для Windows включите
компонент Tcl/Tk. Runtime-зависимости входят в стандартную библиотеку.

```powershell
git clone https://github.com/almuleev/crc32-checker.git
cd crc32-checker
python crc32_checker.py
```

Также можно запустить `run.bat`.

## Тесты и сборка

```powershell
python -m unittest discover -s tests -v
```

Набор из 20 тестов проверяет известную CRC32, пустой файл, чтение блоками,
адреса Intel HEX, промежутки, ошибки формата, отмену, изменение файла во время
чтения и работу интерфейса. GUI-тестам требуется доступный Tk.

Для portable-сборки используется **Python 3.14.4 x64 и PyInstaller 6.20.0**.
Установите именно Python 3.14.4: эта сборка использует Tcl/Tk 8.6. Более новые
Python 3.14 с Tcl/Tk 9 требуют другой версии упаковщика; spec-файл проверяет
версию Python перед сборкой.

```powershell
py -3.14 -m pip install -r requirements-build.txt
.\build.bat
.\scripts\verify_portable.ps1
.\scripts\package_release.ps1 -Version 1.0.0
```

Готовые EXE, ZIP и `SHA256SUMS.txt` появятся в `dist`. Скрипт проверки копирует
только EXE в отдельную папку, исключает Python из `PATH` дочернего процесса
и проверяет Tk, вычисление, буфер обмена и наличие лицензий в сборке.

GitHub Actions запускает тесты на Python 3.8 и 3.14 в Windows, собирает EXE,
проверяет portable-режим и сохраняет файлы как артефакт сборки. Для упаковки
зафиксирован Python 3.14.4; тесты исходников также работают на новом Python 3.14.
Бинарные файлы публикуются в Releases и не хранятся в Git.

## Устройство проекта

| Файл / каталог | Назначение |
| --- | --- |
| `crc32_core.py` | Чтение файлов, проверка Intel HEX и вычисление CRC32 |
| `crc32_checker.py` | Tkinter-интерфейс и фоновый расчёт |
| `app_metadata.py` | Название, версия и автор |
| `portable_check.py` | Проверка работающей portable-сборки |
| `tests/` | Тесты алгоритма и интерфейса |
| `CRC32Checker.spec`, `version_info.txt` | Упаковка, ресурсы и свойства Windows EXE |
| `scripts/` | Проверка EXE и подготовка файлов релиза |
| `licenses/` | Лицензии включённых компонентов |

Двоичные файлы и адресные промежутки обрабатываются блоками по 1 МиБ.
Для Intel HEX реальные записи хранятся в памяти и сортируются по адресу;
весь разреженный адресный диапазон в память не загружается.
