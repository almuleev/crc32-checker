# CRC32 Checker

Простое приложение для Windows с русским графическим интерфейсом: выбор `.hex`
или `.bin`, вычисление CRC32, просмотр размеров и копирование результата.
Сторонние библиотеки не нужны.

## Запуск

**Portable-версия:** запустите `dist\CRC32Checker.exe` двойным щелчком.
Это один файл для Windows 10/11 x64. Python, Tcl/Tk и установка программы
не требуются: зависимости включены в EXE. Файл можно скопировать в любую
папку или на флешку. При запуске зависимости временно распаковываются в
пользовательскую папку временных файлов; после штатного закрытия они удаляются.
Программа не сохраняет настройки и не требует прав администратора.

**Запуск из исходников:** нужен Python 3.8 или новее с Tkinter
(компонент Tcl/Tk в установщике Python). Дважды щёлкните `run.bat` либо
выполните в папке программы:

```powershell
python crc32_checker.py
```

Нажмите «Выбрать файл…». Расчёт начинается автоматически. После изменения
режима нажмите «Вычислить CRC32». «Копировать» копирует восемь шестнадцатеричных
цифр без префикса. Ctrl+O открывает файл, Esc отменяет текущий расчёт.
Большие файлы обрабатываются в фоновом потоке; окно остаётся доступным.

## Какие данные входят в CRC32

Используется **CRC-32/ISO-HDLC** (CRC-32/IEEE): полином `0x04C11DB7`,
отражённый полином `0xEDB88320`, начальное значение `0xFFFFFFFF`, отражение
входа/выхода, финальный XOR `0xFFFFFFFF`. Реализация — `zlib.crc32`.
Для ASCII `123456789` результат `CBF43926`, для пустого файла — `00000000`.
CRC32 служит для проверки целостности и не является криптографическим хешем.

| Режим | Вход для CRC32 |
| --- | --- |
| Авто, `.bin` | Все исходные байты файла |
| Авто, `.hex` | Данные Intel HEX в порядке возрастания адресов |
| Исходные байты файла | Все байты, в том числе текст, BOM и переводы строк `.hex` |

Для Intel HEX поддерживаются типы записей `00`–`05`, расширенные линейные
и сегментные адреса. Проверяются синтаксис, длины, контрольные суммы строк,
запись EOF и перекрытие адресов. Регистр расширения файла не имеет значения.

Расчёт выполняется от **минимального до максимального адреса данных включительно**.
Внутренние промежутки заполняются байтами `FF`; байты до первого и после
последнего адреса не добавляются. Адреса запуска и служебные записи не входят
в расчёт. Диапазон, число реальных байтов данных и число байтов заполнения
показаны в окне. Для совпадения с другой утилитой должны совпадать алгоритм,
адресный диапазон и способ заполнения промежутков.

Intel HEX — текстовый формат с записями, начинающимися с `:`. Если `.hex`
содержит двоичные данные или иной текстовый формат, используйте режим
«Исходные байты файла». Этот режим не преобразует текстовый дамп вроде `AA BB`
в двоичные байты.

Двоичные файлы и адресные промежутки читаются/считаются блоками по 1 МиБ.
Intel HEX хранит реальные записи данных в памяти и сортирует их по адресу;
полный разреженный адресный диапазон в память не загружается.

## Сборка portable EXE

В Windows с Python 3.14 x64:

```powershell
py -3.14 -m pip install -r requirements-build.txt
.\build.bat
```

Результат — `dist\CRC32Checker.exe`. PyInstaller 6.20.0 упаковывает Python,
Tcl/Tk и приложение в один EXE без консольного окна. Параметры сборки находятся
в `CRC32Checker.spec`. [Документация PyInstaller](https://pyinstaller.org/en/stable/operating-mode.html).

Для проверки именно собранного EXE предусмотрен служебный режим:

```powershell
$process = Start-Process .\dist\CRC32Checker.exe -ArgumentList '--self-test', 'portable-check.json' -PassThru -Wait -WindowStyle Hidden
$process.ExitCode
Get-Content .\portable-check.json
```

Код возврата `0` и `"ok": true` означают успешную проверку CRC32, чтения HEX,
создания окна Tk, расчёта в фоне и копирования результата. Отчёт также содержит
`"frozen": true`, если выполнялся EXE. Обычный запуск не создаёт отчётов.
