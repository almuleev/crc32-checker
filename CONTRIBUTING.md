# Участие в разработке

Сообщения об ошибках и pull requests приветствуются.

Для ошибки расчёта укажите версию, расширение файла, ожидаемую и полученную CRC32,
диапазон адресов и способ заполнения промежутков в утилите, с которой
сравниваете результат. Прикладывайте только файлы, которые можно публиковать.
Для ошибки запуска укажите версию и разрядность Windows.

Перед pull request:

1. Опишите проблему и внесите ограниченное изменение.
2. Для изменения алгоритма добавьте проверку на известных данных.
3. Запустите `python -m unittest discover -s tests -v` в Windows.
4. Для изменения упаковки соберите EXE и выполните `--self-test` по README.

Runtime-зависимости должны оставаться в стандартной библиотеке Python,
если добавление библиотеки не обосновано задачей. Сохраняйте совместимость
исходного кода с Python 3.8 и старше и отзывчивость интерфейса.

Изменения распространяются под MIT, как и остальной код проекта.
