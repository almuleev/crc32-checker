# Changelog

## [1.1.0] — 2026-10-20

- Перетаскивание одного файла из Проводника на любую часть главного окна.
- Автоматический расчёт после перетаскивания с сохранением выбранного режима.
- Поддержка кириллицы, пробелов и скобок в путях без дополнительных зависимостей.
- Проверка папок и нескольких файлов; приём отключён во время расчёта.
- Тесты Windows-сообщений перетаскивания и проверка в portable EXE.

- Зафиксированы Python 3.14.4 и packaging hooks для автоматической сборки:
  PyInstaller 6.20.0 поддерживает ресурсы Tcl/Tk 8.6 этой версии Python.

## [1.0.0] — 2026-10-13

Первый публичный релиз CRC32 Checker.

- Русский графический интерфейс для `.bin` и `.hex`.
- CRC-32/ISO-HDLC по исходным байтам файла или данным Intel HEX.
- Проверка HEX-записей, расширенные адреса и заполнение промежутков `FF`.
- Показ адресного диапазона, размеров данных и заполнения.
- Вычисление в фоне, отмена и копирование результата.
- Portable EXE для Windows x64 с включёнными Python и Tcl/Tk.
- Версия, авторство и лицензия в свойствах EXE и окне «О программе».
- Тесты алгоритма и интерфейса, CI и проверка собранного EXE.
